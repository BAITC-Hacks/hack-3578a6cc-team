# Фильтр алертов

Скрипт отфильтровывает шум из `events.json` и оставляет только события с
уровнем `critical`.

## Запуск

Нужен Python 3. Запустите из корня репозитория:

```bash
python3 filter_alerts.py
```

## Результат

Скрипт печатает три критичных события:

- `disk 90%`
- `payment failed`
- `db timeout`

В конце выводится итоговая строка: `критичных 3`.

Внешние зависимости не используются.
