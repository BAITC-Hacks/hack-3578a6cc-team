# Классификатор обращений

Небольшой скрипт классифицирует обращения из `messages.txt` по категориям
«справка», «жалоба» и «другое» и печатает черновик ответа на русском языке.

## Запуск

Нужен Python 3. Запустите из корня репозитория:

```bash
python3 classifier.py
```

## Результат

Для тестовых обращений категории определяются так:

1. справка
2. жалоба
3. другое
4. жалоба
5. справка

Классификация выполнена простыми правилами по ключевым словам, без внешних
зависимостей.

## Фильтр алертов

`filter_alerts.py` читает `events.json`, оставляет только события с уровнем
`critical` и печатает их вместе с итогом.

```bash
python3 filter_alerts.py
```

В тестовом наборе найдено 3 критичных события: `disk 90%`, `payment failed` и
`db timeout`.
